# human-escalation

## 사람에게 확인해야 하는 경우
- 실제 환경변수 값, 토큰, service role key가 필요할 때.
- Supabase SQL Editor에 실제 적용이 필요할 때.
- RLS 완화 또는 권한 정책 변경이 필요할 때.
- `middleware.ts`, `AuthGate`, `PortalShell` 변경이 큰 회귀를 만들 수 있을 때.
- 빌드 실패를 고치려면 서비스 기능 리팩터링이 필요한 때.
- 문서에서 확인되지 않은 내부 정책을 확정해야 할 때.

## 보고 방식
- 무엇을 확인해야 하는지 한 문장으로 쓴다.
- 지금까지 확인한 파일과 근거를 제시한다.
- 가능한 선택지를 짧게 제안한다.
