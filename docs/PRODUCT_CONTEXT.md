# PRODUCT_CONTEXT

## 현재 확인된 제품 영역
- 로그인과 승인 기반 포털 진입.
- 홈 뉴스 브리핑과 공지/팝업성 정보.
- 선거 중계표와 홈/장비/일정배정 오버레이.
- 관리자 전용 날씨와 강수 출동 추천.
- 근무표와 각종 일정 관리.
- 휴가 신청과 월별 휴가 정보.
- 베스트리포트 평가와 리뷰어/팀장 기능.
- 장비 현황과 대여/반납 관련 화면.
- 관리자 기능과 사용자/운영 데이터 관리.
- 마이페이지와 개인 배정/설정.

## 권한 맥락
- 역할 enum은 `member`, `outlet`, `reviewer`, `observer`, `partner`, `desk`, `team_lead`, `admin`을 포함한다.
- `approved`는 보호 영역 접근의 핵심 조건이다.
- 권한 판단은 UI, AuthGate, RLS가 함께 담당한다.

## 주의
- 내부 업무명은 필요한 수준 이상으로 확대 설명하지 않는다.
- 기능 설명은 사용자 흐름 이해에 필요한 만큼만 유지한다.
- 정확하지 않은 도메인 세부사항은 `미확인`으로 둔다.
